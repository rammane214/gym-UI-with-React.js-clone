# Gym React Project

A modern, responsive gym website built with React, Vite, and GSAP animations. This project showcases a professional fitness website with smooth animations and interactive components.

## 🏋️ Features

- **Hero Section**: Eye-catching landing area with animated elements
- **Programs**: Display of various fitness programs and training options
- **Reasons**: Compelling reasons to choose the gym
- **Plans**: Membership and pricing plans
- **Testimonials**: Customer reviews and success stories
- **Join Section**: Call-to-action for new members
- **Footer**: Comprehensive site navigation and information

## 🚀 Technologies Used

- **React 19.2.0** - Modern React with latest features
- **Vite 7.2.4** - Fast development server and build tool
- **GSAP 3.14.2** - Professional animation library
- **@gsap/react 2.1.2** - React integration for GSAP
- **CSS3** - Custom styling with responsive design

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd gym-react-project
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

## 🛠️ Development

Start the development server:
```bash
npm run dev
# or
yarn dev
```

The application will be available at `http://localhost:5173`

## 🏗️ Build

Build for production:
```bash
npm run build
# or
yarn build
```

Preview the production build:
```bash
npm run preview
# or
yarn preview
```

## 🧹 Linting

Check for code issues:
```bash
npm run lint
# or
yarn lint
```

## 📁 Project Structure

```
src/
├── assets/
│   ├── component/          # React components
│   │   ├── Hero/

│   │   ├── Reasons/
│   │   ├── plans/
│   │   ├── Testiomonial/
│   │   ├── Join/
│   │   └── Footer/
│   └── [other assets]
├── Data/                   # Static data files
├── App.css                # Main styles
├── App.jsx                # Main application component
├── index.css              # Global styles
└── main.jsx               # Application entry point
```

## 🎨 Customization

- Modify components in `src/assets/component/` to update sections
- Update styles in `src/App.css` and `src/index.css`
- Add new data in `src/Data/` directory
- Configure GSAP animations in individual components
